# AutoMan - Martelinho de Ouro

Site de portfólio profissional para serviços de estética automotiva, especializado em Martelinho de Ouro.

## Funcionalidades

- **Design Premium**: Tema escuro com detalhes em dourado, ideal para o nicho automotivo de luxo.
- **Carrossel de Herói**: Destaque para os melhores trabalhos e slogans impactantes.
- **Efeitos Parallax**: Navegação moderna e fluida.
- **Catálogo de Serviços**: Exibição dinâmica de serviços como Martelinho de Ouro, Polimento Técnico e Vitrificação.
- **Seção de Parceiros**: Logos de marcas parceiras integradas via API.
- **Formulário de Contato**: Sistema funcional para captação de leads.
- **Localização**: Seção dedicada para fácil localização da oficina.

## Tecnologias Utilizadas

- **Frontend**: React, Tailwind CSS, Framer Motion (animações), Lucide React (ícones).
- **Backend**: Express.js, Node.js.
- **Banco de Dados**: PostgreSQL com Drizzle ORM.
- **Gerenciamento de Estado**: TanStack Query (React Query).

## Como Executar

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Configure o banco de dados PostgreSQL e a variável de ambiente `DATABASE_URL`.

3. Sincronize o banco de dados:
   ```bash
   npm run db:push
   ```

4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
